# EduFlow

EduFlow is an online learning platform landing page that offers industry-focused courses in Programming, AI, Cloud Computing, Web Development, and Data Science. The goal is to help learners build practical skills and support their career growth.

## Overview

This project contains the design for the EduFlow landing page, built with a clean **light theme** (soft sage background with green accents) for a calm, readable learning experience.

## Page Sections

1. **Navigation** – Logo, links (Home, Courses, About Us, Contact) and a *Get Started* button
2. **Hero** – "Learn Future Skills Today" headline, supporting text, call-to-action and hero image
3. **Why Choose EduFlow** – Overview of the platform and its focus areas
4. **Key Features** – Online Courses, Expert Mentors and Certificates
5. **Popular Courses** – Python & Data Structures, Applied Machine Learning, Cloud Computing Essentials, Full-Stack Web Development
6. **Learn Your Way** – Practical skills with personal mentor support
7. **How It Works** – Sign up, choose a course, learn and build, get certified
8. **Stats** – Learners, courses, mentors and satisfaction rate
9. **Testimonials** – Feedback from learners
10. **Pricing** – Starter, Pro and Teams plans
11. **FAQ** – Common questions about courses and certificates
12. **Call to Action** – Final prompt to start learning
13. **Footer** – Course, company and support links, plus copyright
